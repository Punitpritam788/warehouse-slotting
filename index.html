How it works

From master data to a measured layout.

Every record comes from documented rules. Derived values are computed from source rows, never drawn on their own.

1

Generate

Warehouses, zones, locations, SKUs and 100,000 order lines with fast and slow movers, oversized and hazard goods, and two demand peaks.

2

Slot

Baseline drops each SKU in a random compatible spot. Optimized gives the busiest SKU the nearest spot that fits.

3

Measure

The same demand runs on both layouts: pick distance, lines per labor hour and replenishment workload.

4

Test

Five labelled edge cases are injected. A detector that never sees the answer key has to find exactly those.

Results

Same orders. Less walking.

Both layouts replay identical demand. Grey is the baseline, amber is velocity-ranked.

Edge cases

Break it on purpose, then catch it.

Each case is added as new labelled rows, so valid data is never corrupted. The detector reads only the input tables.
